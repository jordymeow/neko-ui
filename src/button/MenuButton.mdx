# NekoMenuButton and NekoMenuItem

NekoMenuButton is a customizable dropdown menu component for React applications. It provides a button that, when clicked, displays a list of NekoMenuItem components. This component is ideal for creating dropdown menus with various options, including support for pro-only features.

## Overview

The NekoMenuButton and NekoMenuItem components offer:

- A customizable button that opens a dropdown menu
- Support for multiple menu items
- Pro-only feature support
- Disabled state for both the main button and individual menu items
- Custom styling options
- Separators between menu items

## Usage

To use NekoMenuButton in your React application, import both NekoMenuButton and NekoMenuItem components:

```jsx
import { NekoMenuButton, NekoMenuItem } from './path-to-neko-ui';

function MyDropdownMenu() {
  return (
    <NekoMenuButton title="Options">
      <NekoMenuItem onClick={() => console.log('Option 1 clicked')}>Option 1</NekoMenuItem>
      <NekoMenuItem onClick={() => console.log('Option 2 clicked')}>Option 2</NekoMenuItem>
      <NekoMenuItem onClick={() => console.log('Option 3 clicked')}>Option 3</NekoMenuItem>
    </NekoMenuButton>
  );
}
```

## Features

### Basic Dropdown Menu

Create a simple dropdown menu with multiple options:

```jsx
<NekoMenuButton title="Actions">
  <NekoMenuItem onClick={handleEdit}>Edit</NekoMenuItem>
  <NekoMenuItem onClick={handleDelete}>Delete</NekoMenuItem>
  <NekoMenuItem onClick={handleShare}>Share</NekoMenuItem>
</NekoMenuButton>
```

### Pro-only Features

Mark certain menu items as pro-only features:

```jsx
<NekoMenuButton title="Advanced" isPro={userIsPro}>
  <NekoMenuItem onClick={handleBasicFeature}>Basic Feature</NekoMenuItem>
  <NekoMenuItem onClick={handleProFeature} requirePro>Pro Feature</NekoMenuItem>
</NekoMenuButton>
```

### Disabled State

Disable the entire menu button or individual menu items:

```jsx
<NekoMenuButton title="Actions" disabled={isProcessing}>
  <NekoMenuItem onClick={handleAction1}>Action 1</NekoMenuItem>
  <NekoMenuItem onClick={handleAction2} disabled={!canPerformAction2}>Action 2</NekoMenuItem>
</NekoMenuButton>
```

### Separators

Add separators between menu items:

```jsx
<NekoMenuButton title="Options">
  <NekoMenuItem onClick={handleOption1}>Option 1</NekoMenuItem>
  <NekoMenuItem onClick={handleOption2}>Option 2</NekoMenuItem>
  <NekoMenuItem separator>Advanced Options</NekoMenuItem>
  <NekoMenuItem onClick={handleAdvancedOption1}>Advanced Option 1</NekoMenuItem>
</NekoMenuButton>
```

### Custom Styling

Apply custom styles to the menu button:

```jsx
<NekoMenuButton 
  title="Custom Style" 
  style={{ backgroundColor: 'purple' }}
  titleStyle={{ fontWeight: 'bold' }}
>
  <NekoMenuItem onClick={handleCustomAction}>Custom Action</NekoMenuItem>
</NekoMenuButton>
```

## Accessibility

The component supports keyboard navigation and uses appropriate ARIA attributes. The dropdown menu closes when clicking outside of it, improving usability.
