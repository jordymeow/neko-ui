# NekoButton Component

The NekoButton is a versatile and customizable button component designed for easy integration and use in React applications.

## Overview

NekoButton is a styled button that supports various appearances and states, including:
- Different color schemes (primary, secondary, danger, success)
- Icons
- Busy state with spinner
- Rounded shape
- Pro-user restrictions

## Basic Usage

Import the NekoButton component and use it in your React application:

```jsx
import { NekoButton } from './path-to-neko-ui';

function MyComponent() {
  return (
    <NekoButton onClick={() => console.log('Button clicked!')}>
      Click me
    </NekoButton>
  );
}
```

## Examples

### Primary Button

```jsx
<NekoButton onClick={() => alert('Clicked!')}>
  Primary Button
</NekoButton>
```

### Secondary Button with Icon

```jsx
<NekoButton 
  className="secondary"
  icon="edit"
  onClick={() => console.log('Edit clicked')}
>
  Edit
</NekoButton>
```

### Busy Button

```jsx
<NekoButton 
  isBusy={true}
  busyText="Loading..."
  onClick={() => {}}
>
  Submit
</NekoButton>
```

### Rounded Button

```jsx
<NekoButton 
  rounded={true}
  icon="setting"
  onClick={() => console.log('Settings clicked')}
/>
```

### Pro-only Button

```jsx
<NekoButton 
  requirePro={true}
  isPro={false}
  onClick={() => console.log('Upgrade to Pro')}
>
  Pro Feature
</NekoButton>
```
