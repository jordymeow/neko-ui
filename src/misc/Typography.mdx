# NekoTypo

The NekoTypo component offers a set of pre-styled typographic elements for building consistent and visually appealing text content within your application's UI. It provides options for headings, paragraphs, labels, and generic text spans.

## Usage

NekoTypo leverages styled-components to provide styled elements that adhere to your application's design system. You can use them directly or customize them further using props and class names.

## Props

<Controls />

### Headings (H1 - H6)

<aside style={{backgroundColor: '#f2f2f2', padding: '10px', borderRadius: '4px'}}>
  **Props:**

  - `h1`, `h2`, `h3`, `h4`, `h5`, `h6` (boolean): Use these props to render the corresponding heading level (H1 - H6). Only use one heading prop per element.
</aside>

```jsx
<NekoTypo h1>This is a Heading 1</NekoTypo>
<NekoTypo h3>This is a Heading 3</NekoTypo>
```

### Paragraphs

Use the p prop to render paragraph text.

```jsx
<NekoTypo p>Lorem ipsum dolor sit amet, consectetur adipiscing elit. Curabitur euismod magna at lacinia tincidunt. Donec sed odio dui. Fusce semper quam id lobortis porttitor.</NekoTypo>
```

### Labels

Use the label prop to render text for form labels.

```jsx
<label>
  <NekoTypo label>Email Address:</NekoTypo>
  <input type="email" />
</label>
```

### Text Spans

Use the span prop for generic inline text elements.

```jsx
<NekoTypo span>Some inline text content.</NekoTypo>
```

### Bold Text

The bold prop enables bold styling for any NekoTypo element.

```jsx
<NekoTypo p bold>This text is bold.</NekoTypo>
```

## Custom Styles

While NekoTypo offers built-in styles, you can further customize the appearance using:

- Global CSS or scoped styles to override default styles.
- Class names like neko-typo and neko-typo-h1 for targeted styling.

## Usage Considerations

- Choose appropriate heading levels to structure your content hierarchy effectively.
- Maintain a clear visual distinction between headings, paragraphs, and labels to enhance readability.
- Use bold text sparingly to emphasize important points without overwhelming users.
