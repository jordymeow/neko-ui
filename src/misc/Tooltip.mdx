# NekoTooltip

The NekoTooltip component provides a customizable tooltip that appears on hover or focus to display additional information for an element within your application.

## Basic Usage

```jsx
<NekoTooltip text="This is some tooltip text">
  Hover me for tooltip!
</NekoTooltip>
```

This renders a basic tooltip that appears when hovering over the text "Hover me for tooltip!".

## Tooltip Content

The content of the tooltip is provided using the text prop. You can include any HTML or text content within the quotes.

## Tooltip Position

The position prop controls where the tooltip appears relative to the target element. Available options include:

- **top**: Tooltip appears above the target element (default).
- **right**: Tooltip appears to the right of the target element.
- **bottom**: Tooltip appears below the target element.
- **left**: Tooltip appears to the left of the target element.

## Visual Style

While the component offers a styled appearance, you can further customize it by:

- Overriding styles in your global CSS or scoped styles.
- Referencing the component's class names (e.g., .neko-tooltip, .neko-tooltip.top).

## Usage Considerations

- Tooltips are helpful for providing additional context without cluttering the main UI.
- Use tooltips strategically to avoid overwhelming users with excessive information.
- Ensure proper positioning to prevent the tooltip from being obscured by other UI elements.
