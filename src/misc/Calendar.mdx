# NekoCalendar

The NekoCalendar component provides a visually appealing and interactive calendar view for your application. It allows users to view events and potentially interact with them.

## Basic Usage

```jsx
<NekoCalendar
  events={[
    { key: '1', date: new Date(2024, 6, 15), draggable: true }, // Sample event object
  ]}
  onEventClicked={(event) => console.log("Event clicked:", event)}
  onEventMoved={(newDate, event) => console.log("Event moved to:", newDate, event)}
/>
```

This renders a basic NekoCalendar for the current month, displaying a sample event and logging information to the console when the event is clicked or moved.

## Event Data and Rendering

The events prop takes an array of event objects. The component expects these objects to have at least a date property representing the date of the event, and a key property for unique identification. You can optionally define a draggable property to allow users to drag and drop events within the calendar.

The eventBuilder prop is a function that you can use to customize how events are displayed within the calendar. It receives the event object as an argument and should return the content to be displayed for that event.

## User Interaction

NekoCalendar supports the following user interactions:

- **Clicking on an event**: Clicking on an event triggers the onEventClicked callback function, allowing you to implement custom event handling logic.
- **Dragging and dropping events (optional)**: If an event object has the draggable property set to true, users can drag and drop it to a different date within the calendar. This triggers the onEventMoved callback function, allowing you to update the event data based on the new date.

## Styling and Customization

The component uses styled-components for styling, providing a basic visual style out of the box. You can further customize the appearance using CSS or styled-components.

## Advanced Features (Optional)

The provided code also includes props for disableDaysBefore and disableDaysAfter, which you can use to restrict the selectable date range within the calendar.
