# NekoQuickLinks & NekoLink

The NekoQuickLinks component provides a styled breadcrumb-like navigation element for hierarchical UIs. It renders NekoLink components that represent navigation items.

## NekoQuickLinks

NekoQuickLinks manages the overall navigation state and appearance. It accepts child NekoLink elements and handles active link styling.

## NekoLink

NekoLink represents individual navigation items within the NekoQuickLinks component. It displays a title and optionally a count or loading indicator.

## Basic Usage

```jsx
import { NekoQuickLinks, NekoLink } from '@your-component-library/path/to/nekoquicklinks';

function MyLinks() {
  const [value, setValue] = React.useState('home');

  const handleClick = (newValue) => {
    setValue(newValue);
  };

  return (
    <NekoQuickLinks name="navigation" value={value} onChange={handleClick}>
      <NekoLink title="Home" value="home" />
      <NekoLink title="Messages" value="messages" count={10} />
      <NekoLink title="Settings" value="settings" />
    </NekoQuickLinks>
  );
}
```

This renders a NekoQuickLinks component with three child NekoLink items: "Home", "Messages" (with a count of 10), and "Settings". Clicking on a link triggers the handleClick function, updating the active state and potentially reloading data based on the selected link value.

## Styling and States

- NekoQuickLinks uses a styled container to arrange links horizontally.
- NekoLink styles individual links with hover effects and active state highlighting.
- Links display their title and optionally a count or loading indicator. The count can be used to represent unread messages or similar notifications.
- The loading indicator is displayed using a NekoIcon component with a spinning animation.
