# NekoTextArea Component

NekoTextArea is a customizable textarea component for React applications. It offers enhanced functionality over the standard HTML textarea, including character/word counting, custom styling, and additional event handling.

## Overview

The NekoTextArea component provides a rich text input area with features such as:

- Character or word counting
- Custom styling with styled-components
- Read-only mode
- Full height option
- Maximum length restriction
- Disabled state
- Tab to spaces conversion
- Custom event handling for Enter key and blur events

## Usage

To use the NekoTextArea component in your React application, import it and include it in your JSX:

```jsx
import { NekoTextArea } from './path-to-neko-ui';

function MyComponent() {
  const [text, setText] = useState('');

  return (
    <NekoTextArea
      name="myTextArea"
      value={text}
      onChange={(newValue) => setText(newValue)}
      placeholder="Enter your text here"
      rows={6}
      description="This is a sample textarea"
      countable="chars"
    />
  );
}
```

## Features

### Character/Word Counting

Enable character or word counting with the countable prop:

```jsx
<NekoTextArea countable="chars" />
// or
<NekoTextArea countable="words" />
```

### Full Height Mode

Make the textarea occupy the full height of its container:

```jsx
<NekoTextArea fullHeight />
```

### Read-Only Mode

Set the textarea to read-only:

```jsx
<NekoTextArea readOnly />
```

### Tab to Spaces

Convert tab key presses to spaces:

```jsx
<NekoTextArea tabToSpaces />
```

### Custom Event Handling

Handle Enter key presses and blur events:

```jsx
<NekoTextArea
  onEnter={(value, name) => console.log('Enter pressed', value, name)}
  onBlur={(value, name) => console.log('Blurred', value, name)}
/>
```

## Accessibility

The component maintains standard textarea accessibility features and provides visual feedback for disabled states.
