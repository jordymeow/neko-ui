# NekoInput Component

NekoInput is a versatile input component for React applications. It provides enhanced functionality over standard HTML inputs, including support for comma-separated arrays, custom styling, and various event handlers.

## Overview

The NekoInput component offers features such as:

- Support for text and number input types
- Handling of comma-separated array inputs
- Customizable styling
- Description text
- Read-only mode
- Min/max value constraints for number inputs
- Character limit
- Reset functionality

## Usage

To use NekoInput in your React application, import it and include it in your JSX:

```jsx
import { NekoInput } from './path-to-neko-ui';

function MyComponent() {
  const [inputValue, setInputValue] = useState('');

  return (
    <NekoInput
      name="myInput"
      value={inputValue}
      onChange={(newValue) => setInputValue(newValue)}
      placeholder="Enter text here"
      description="This is a sample input"
    />
  );
}
```

## Features

### Input Types

NekoInput supports 'text' and 'number' input types:

```jsx
<NekoInput type="text" />
<NekoInput type="number" min={0} max={100} step={1} />
```

### Comma-Separated Array Input

Enable comma-separated array input:

```jsx
<NekoInput isCommaSeparatedArray value={['item1', 'item2']} />
```

### Description

Add a description below the input:

```jsx
<NekoInput description="Enter your username" />
```

### Read-Only Mode

Set the input to read-only:

```jsx
<NekoInput readOnly value="This cannot be edited" />
```

### Character Limit

Set a maximum character limit:

```jsx
<NekoInput maxLength={50} />
```

### Reset Functionality

Add a reset button to clear the input:

```jsx
<NekoInput value={inputValue} onReset={() => setInputValue('')} />
```

### Custom Event Handling

Handle various input events:

```jsx
<NekoInput
  onChange={(newValue, name) => console.log('Value changed', newValue, name)}
  onEnter={(value, name) => console.log('Enter pressed', value, name)}
  onBlur={(value, name) => console.log('Input blurred', value, name)}
  onFinalChange={(value, name) => console.log('Final value', value, name)}
/>
```

## Accessibility

The component maintains standard input accessibility features and provides visual feedback for disabled and read-only states.
