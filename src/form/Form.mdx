# NekoForm Component

NekoForm is a simple container component for React applications, designed to provide consistent styling for form elements. It's particularly useful for organizing and styling NekoInput and NekoTextarea components.

## Overview

The NekoForm component offers:

- A container for form elements
- Consistent styling for labels and input margins
- Flexibility to include any child components

## Usage

To use NekoForm in your React application, import it and wrap your form elements:

```jsx
import { NekoForm, NekoInput, NekoTextarea } from './path-to-neko-ui';

function MyForm() {
  return (
    <NekoForm>
      <label htmlFor="name">Name:</label>
      <NekoInput id="name" name="name" />

      <label htmlFor="description">Description:</label>
      <NekoTextarea id="description" name="description" />
    </NekoForm>
  );
}
```

## Props

NekoForm does not require any props. It serves as a styled wrapper for form elements, allowing flexible layout and styling of inputs and labels within.

## Features

### Consistent Label Styling

NekoForm automatically styles labels to be block-level elements with a small bottom margin:

```jsx
<NekoForm>
  <label htmlFor="email">Email:</label>
  <NekoInput id="email" name="email" type="email" />
</NekoForm>
```

### Input and Textarea Margins

NekoForm adds a small bottom margin to NekoInput and NekoTextarea components for better spacing:

```jsx
<NekoForm>
  <NekoInput name="firstName" />
  <NekoInput name="lastName" />
  <NekoTextarea name="comments" />
</NekoForm>
```

### Flexibility

You can include any React components or HTML elements as children of NekoForm:

```jsx
<NekoForm>
  <h2>Contact Information</h2>
  <NekoInput name="phone" />
  <p>Please enter your phone number above.</p>
  <button type="submit">Submit</button>
</NekoForm>
```

## Styling

NekoForm uses styled-components for styling. It applies the following styles:

- Labels are set to display: block with a margin-bottom of 3px
- NekoInput and NekoTextarea components receive a margin-bottom of 5px

You can further customize the styling by targeting the .neko-form class in your CSS.

## Accessibility

While NekoForm doesn't directly add accessibility features, its structure encourages good accessibility practices by promoting the use of labels with form inputs. Remember to include appropriate ARIA attributes and to associate labels with inputs using matching for and id attributes when building your forms.
