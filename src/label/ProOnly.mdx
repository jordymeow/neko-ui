# ProOnly Component

The ProOnly component is a styled tag that indicates features or content available only to pro users.

## Overview

ProOnly is a small, yellow tag that displays "Pro Only" text. It's designed to be easily noticeable and can be used inline with other content or as a standalone element. When clicked, it redirects users to the MeowApps website.

## Basic Usage

Import the ProOnly component and use it in your React application:

```jsx
import { ProOnly } from './path-to-neko-ui';

function MyComponent() {
  return (
    <div>
      <h2>Feature Name <ProOnly /></h2>
      <p>This is a pro-only feature.</p>
    </div>
  );
}
```

```jsx

```

## Styling

The ProOnly component is styled using styled-components. It features:

- Yellow background color
- Rounded corners
- Uppercase white text
- Hover effect (brightness increase)

You can further customize the appearance by passing additional className props or modifying the styled component definition.

## Accessibility

The ProOnly tag is rendered as an anchor (\<a\>) element, making it keyboard accessible and allowing users to open the pro subscription page in a new tab.

## Notes

- The component automatically links to 'https://meowapps.com' when clicked.
- It can be hidden by setting the show prop to false.
- The tag is designed to be small and unobtrusive, with a font size of 9px.
