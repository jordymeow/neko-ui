# NekoTabs and NekoTab

NekoTabs is a flexible and feature-rich tab component for React applications, designed to work in conjunction with NekoTab components.

## Overview

NekoTabs provides a customizable tab interface with features such as:

- Responsive design with horizontal scrolling for many tabs
- Support for icons in tab titles
- Pro-only tab options
- Active tab highlighting
- Tab persistence across page reloads
- Controlled and uncontrolled modes

## Basic Usage

Import the NekoTabs and NekoTab components and use them in your React application:

```jsx
import React from 'react';
import { NekoTabs, NekoTab } from './path-to-neko-ui';

function MyComponent() {
  return (
    <NekoTabs currentTab="tab1" onChange={(index, tab, event) => console.log('Tab changed', tab.key)}>
      <NekoTab title="Tab 1" key="tab1">
        <p>Content for Tab 1</p>
      </NekoTab>
      <NekoTab title="Tab 2" key="tab2">
        <p>Content for Tab 2</p>
      </NekoTab>
      <NekoTab title="Pro Tab" key="pro-tab" requirePro={true}>
        <p>This tab is only for Pro users</p>
      </NekoTab>
    </NekoTabs>
  );
}
```

## Features

### Responsive Design

NekoTabs automatically adds scroll buttons when there are too many tabs to fit in the available space.

### Icons in Tab Titles

Add icons to your tab titles for better visual representation:

```jsx
<NekoTab title="Settings" icon="cog">
  <p>Settings content here</p>
</NekoTab>
```

### Pro-only Tabs

Restrict certain tabs to Pro users:

```jsx
<NekoTab title="Advanced Features" requirePro={true}>
  <p>This content is only visible to Pro users.</p>
</NekoTab>
```

### Tab Persistence

Keep the selected tab across page reloads:

```jsx
<NekoTabs keepTabOnReload={true}>
  {/* Tab components */}
</NekoTabs>
```

## Controlled and Uncontrolled Modes

NekoTabs supports both controlled and uncontrolled modes. Use the currentTab prop for controlled mode.

## Styling

NekoTabs and NekoTab use styled-components for styling. The component supports an inversed prop for alternative styling.

## Accessibility

The component uses semantic HTML structure with button elements for tabs, enhancing keyboard accessibility.

## Notes

- The component automatically generates unique keys for tabs if not provided.
- Hidden tabs are skipped when selecting the active tab.
- The component uses the URL search params to persist the selected tab when keepTabOnReload is true.
