# NekoToolbar

The NekoToolbar is a flexible container component designed to create toolbar-like structures in your application. It provides a clean, white background with a subtle shadow, making it stand out from the rest of your UI.

## Overview

NekoToolbar is a horizontal container that aligns its children either to the left or right. It's perfect for grouping action buttons, form controls, or any other UI elements that need to be presented in a toolbar format.

## Basic Usage

To use the NekoToolbar, simply import it and wrap your toolbar items inside:

```jsx
import { NekoToolbar } from './path-to-neko-ui';

function MyToolbar() {
  return (
    <NekoToolbar>
      <button>Action 1</button>
      <button>Action 2</button>
      <input type="text" placeholder="Search..." />
    </NekoToolbar>
  );
}
```

## Alignment

You can control the alignment of the toolbar items using the align prop:

```jsx
<NekoToolbar align="right">
  <button>Save</button>
  <button>Cancel</button>
</NekoToolbar>
```

The align prop accepts two values: 'left' (default) or 'right'.

## Styling

NekoToolbar comes with a default style that includes:

- White background
- Rounded corners (10px border-radius)
- Subtle box shadow
- 10px padding on all sides

The component uses CSS variables for theming. The text color is controlled by the --neko-font-color variable.

## Composition

NekoToolbar is designed to be flexible. You can include any type of child components inside it:

```jsx
<NekoToolbar>
  <span>Status: Online</span>
  <button>Refresh</button>
  <select>
    <option>Option 1</option>
    <option>Option 2</option>
  </select>
</NekoToolbar>
```

The toolbar automatically adds a small margin (5px) between child elements for proper spacing.

By leveraging the NekoToolbar component, you can create consistent and visually appealing toolbar sections throughout your application with ease.
