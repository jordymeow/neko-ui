# Neko Colors

`useNekoColors` is a hook that returns the NekoUI colors. It is used to get the colors defined in the NekoUI.

## Usage

```jsx
import { useNekoColors } from 'NekoUI';

const { colors } = useNekoColors();

const MyComponent = () => {
  return <div style={{ color: colors.black }}>Hello World</div>;
};
```
