# NekoContainer

The NekoContainer component provides a versatile layout for building content sections within your application. It offers a header, content area, and footer for flexible organization.

## Basic Usage

```jsx
import { NekoContainer } from '@your-component-library/path/to/nekocontainer';

<NekoContainer header="Section Title">
  This is the content of the container.
  <p>You can add paragraphs and other elements here.</p>
</NekoContainer>
```

This renders a basic NekoContainer with a header and content area.

## Customization

NekoContainer offers different options to customize its appearance:

- **Header and Footer**: You can add content to the header and footer sections using React elements.
- **Alignment**: You can control the alignment of content within the header and footer using the headerAlign and footerAlign props, which accept either 'left' or 'right'.
- **Styles**: You can apply custom styles to the overall container, content area, header, and footer using the style, contentStyle, and headerStyle props (not mentioned in the provided code).

Here's an example with a footer and right-aligned content:

```jsx
<NekoContainer
  header="Section Title"
  footer="Additional Information"
  footerAlign="right"
>
  This content is displayed in the container.
</NekoContainer>
```

## Styling with Class Names

The NekoContainer component also supports custom class names for further styling flexibility. You can apply a class name using the className prop.
