# NekoPage

The NekoPage component provides a layout for application pages with built-in error handling for the WordPress REST API.

## Functionality

NekoPage displays your page content and handles potential errors when interacting with the WordPress REST API. If a critical error occurs, it displays a modal dialog with details about the error.

### Error Handling

The component checks for errors provided through the `nekoErrors` prop (assumed to be an array). If a critical error is found, it displays a modal with the following information:

- **Error Message:** A user-friendly message explaining the issue.
- **Technical Details:** More technical details about the error, including:
    - URL of the API request that failed
    - Error code
    - Error message
- **Optional Response Body:** If available, the component allows displaying the raw response body from the server (requires user interaction).
- **Learn More Button:** A button linking to documentation on WordPress debugging.

## Basic Usage

```jsx
<NekoPage>
  {/* Your page content goes here */}
  <p>This is the content of the page.</p>
</NekoPage>
```

This renders a basic NekoPage layout with your content.
